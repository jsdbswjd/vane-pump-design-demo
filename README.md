# 베인 펌프 캠링 형상 모델링 및 설계조건 탐색

명화공업의 공개 베인 펌프 특허를 참고하여 캠링 형상을 구현하고, 형상변수가 **이론토출용적과 기하 제약**에 미치는 영향을 분석한 개인 프로젝트입니다.

동력시스템 설계 직무를 이해하기 위해 진행했으며, 외경을 고정한 상태에서 목표 이론토출용적을 만족하는 최소 축방향 두께 후보를 탐색했습니다.

## 주요 결과

목표 이론토출용적을 **13 cc/rev**로 설정하고, 형상계수 `K`와 접선각 `α`의 **713개 조합**을 탐색했습니다.

| 항목 | 기준 형상 | 선정 후보 |
|---|---:|---:|
| 형상계수 K | 2.00 | 2.65 |
| 접선각 α | 10° | 13° |
| 축방향 두께 | 14.00 mm | 약 9.01 mm |
| 이론토출용적 | 약 13.88 cc/rev | 약 13.00 cc/rev |
| 최소 반경 여유 | 약 2.31 mm | 약 0.51 mm |
| 최대 압력각 | 약 23° | 약 28° |

두께를 줄이는 후보에서 반경 여유가 감소하고 압력각이 증가하는 관계를 확인했습니다. 선정 후보는 설정한 기하 제약을 만족하지만, 제약 한계에 가까워 제조공차와 열변형에 대한 추가 검토가 필요합니다.

**9.01 mm는 설정한 모델·제약·탐색 범위 내 최소 두께 후보입니다. 실제 제품의 소형화 또는 효율 향상을 검증한 결과는 아닙니다.**

다음 순서로 변수를 변경하면 모델의 특성을 확인하기 좋습니다.

1. **K: 2 → 2.5**  
   캠링 형상과 이론토출용적의 변화를 비교합니다.
2. **접선각: 10 → 13°**  
   최소 반경과 최대 압력각의 변화를 확인합니다.
3. **축방향 두께: 14 → 11 mm**  
   목표 이론토출용적 충족 여부를 확인합니다.
4. **회전수 변경**  
   회전당 토출용적은 유지되고 이상 유량이 변하는 것을 확인합니다.
5. **목표 토출용적 설정 → ‘두께 최소 조건 찾기’**  
   기하 제약을 만족하는 최소 두께 후보를 탐색합니다.

## Python 실행

Python 파일들이 있는 폴더에서 실행합니다.

```bash
python -m pip install -r requirements.txt
```

### 슬라이더 기반 형상·토출용적 비교

```bash
python vane_python.py
```

Matplotlib GUI 창을 사용하므로 GUI를 지원하는 데스크톱 환경이 필요합니다.

정적 미리보기 이미지는 다음 명령으로 생성합니다.

```bash
python vane_python.py --save
```

### 설계조건 탐색

```bash
python optimize_vane.py --target 13
```

K·접선각 조합별 필요 두께와 기하 제약을 검토하고, 결과를 `grid_results.csv`에 저장합니다.

### 수치 검증

```bash

```

형상 연결, 대칭, 체적 계산, 변수별 비례 관계와 제약 판정을 확인합니다.

## 모델 설정과 기하 제약

특허에서 참고한 값과 이번 모델에서 추가로 설정한 조건을 구분했습니다.

| 항목 | 설정값 | 구분 |
|---|---:|---|
| 외경 | 53.5 mm | 특허 비교 조건 참고 |
| 기준 축방향 두께 | 14 mm | 특허 비교 조건 참고 |
| 형상계수 K | 1.5–3 | 특허 범위 참고 |
| 접선각 α | 4–15° | 특허 범위 참고 |
| 외벽 두께 | 2 mm | 추가 가정 |
| 최대 내부 반경 | 24.75 mm | 외경과 외벽 두께로 계산 |
| 로터 반경 | 19 mm | 추가 가정 |
| 베인 수 | 12개 | 추가 가정 |
| 축방향 두께 범위 | 8–18 mm | 탐색 범위 |
| 회전수 범위 | 500–5,000 rpm | 데모 운전 범위 |

기하 제약은 다음과 같이 설정했습니다.

- 최소 반경 여유 ≥ 0.5 mm
- 최대 베인 돌출량 ≤ 6 mm
- 최대 압력각 ≤ 30°

이 제약값은 **이번 과제의 비교용 설정**이며, 제조공차나 강도 검증을 통해 확정한 산업 설계 기준이 아닙니다.

반경 여유는 다음과 같이 정의합니다.

```text
최소 반경 여유 = 캠링 최소 내부 반경 − 로터 반경
```

이는 베인의 최소 기하 돌출량에 해당하며, 베인 끝과 캠링 사이의 밀봉 틈새와는 다릅니다.

또한 최대 내부 반경과 로터 반경이 고정되어 있어, 이번 탐색에서 최대 돌출량은 모든 후보에서 5.75 mm로 같습니다. 따라서 최대 돌출량 제약은 현재 후보들을 구분하지 않지만, 외경이나 로터 반경을 변경할 때 활용할 수 있습니다.

## 캠링 형상 구현

특허의 사이클로이드 식을 사용합니다.

```text
x = R(θ − sinθ) − πR
y = R(1 − cosθ + K)
```

최대 내부 반경을 고정하기 위해 다음 관계를 적용합니다.

```text
R = Rmax / (K + 2)
```

여기서 `R`은 사이클로이드 생성 반경이며, 로터 반경과는 다른 값입니다.

형상 구성 과정은 다음과 같습니다.

1. 사이클로이드 도함수로 접선 방향 계산
2. 접선각 α에 해당하는 접점 `θt = 2α` 계산
3. 접점 T와 단위 접선벡터 `d = (sinα, cosα)` 계산
4. 원점에서 접선에 내린 수선의 발 `F = T − (T·d)d` 계산
5. 반경 `||F||`의 원호, 직선 접선, 사이클로이드 연결
6. x축·y축 대칭으로 전체 캠링 형상 구성

접선각 α는 형상 생성의 입력값입니다. 완성된 형상에서 계산하는 **최대 압력각과는 다른 지표**입니다.

## 챔버 체적과 이론토출용적

베인 두께를 0으로 두고, 인접한 방사형 베인 사이의 챔버 체적을 계산합니다.

```text
V(φ) = b/2 × ∫[φ, φ+2π/Z] {r(ψ)² − rrotor²} dψ
```

- `b`: 축방향 두께
- `Z`: 베인 수
- `r(ψ)`: 캠링 내부 반경
- `rrotor`: 로터 반경

길이 단위가 mm이므로 체적은 mm³로 계산한 뒤 1,000으로 나누어 cc로 변환합니다.

두 로브에서 각 챔버가 회전당 두 번 팽창·수축한다는 전제로 다음 식을 적용합니다.

```text
이론토출용적 D = 2Z(Vmax − Vmin)    [cc/rev]
이상 유량 Q = D × n / 1000         [L/min]
```

형상이 같으면 D는 축방향 두께에 비례합니다. 회전수 n은 회전당 토출용적 D를 바꾸지 않고, 이상 유량 Q를 변화시킵니다.

압력각은 반경 방향과 캠 법선의 각도로 계산합니다.

```text
압력각 = atan(|(dr/dφ) / r|)
```

이는 기하 비교 지표이며, 접촉하중·마모·수명·효율의 예측값은 아닙니다.

## 설계조건 탐색 방법

**목적:** 목표 이론토출용적을 만족하면서 축방향 두께 b 최소화

- K: 1.5–3.0, 간격 0.05 → 31개
- α: 4–15°, 간격 0.5° → 23개
- 총 형상 조합: 31 × 23 = 713개

각 형상에서 두께 1 mm의 토출용적 `D1`을 구한 뒤 필요한 두께를 계산합니다.

```text
필요 두께 = max(8 mm, 목표 토출용적 / D1)
```

필요 두께가 18 mm 이하이고 기하 제약을 만족하는 후보 중 가장 작은 두께를 선택합니다. 두께는 별도 격자로 탐색하지 않고, 토출용적과 두께의 비례 관계로 계산합니다.

Python 최적화 스크립트는 선정 후보를 더 촘촘한 적분 조건으로 재평가합니다.

## 모델 범위와 추가 검토

이번 구현은 사이클로이드의 접선을 중심 원호에 직접 연결하는 **C1 접선 근사 모델**입니다. 위치와 접선은 연결되지만 곡률 연속 C2를 보장하지 않으며, 특허의 상세 블렌드 형상을 완전히 재현하지 않습니다.

다음 항목은 모델에 포함하지 않았습니다.

- 유한 베인 두께와 실제 포트 형상·타이밍
- 누설, 압축성, 충전 부족과 캐비테이션
- 압력·마찰·온도·윤활에 따른 거동
- 제조공차와 열변형
- 베인 슬롯 깊이·강도 및 접촉하중
- 토출 맥동과 압력·회전수별 체적효율·전효율

실제 설계 후보로 발전시키려면 유한 베인·포트 형상을 반영한 체적 계산, 공차·열변형 검토, 유동 해석과 성능시험이 필요합니다.
